# SnappsHub - Universal Category & Download Hub
Designed By Alamin Saheb 😎

## 📂 ফাইল স্ট্রাকচার:
```
snappshub.github.io/
├── index.html        (মেইন ওয়েবসাইট — অটো রেসপনসিভ, ৫-সেকেন্ড টাইমার ও অ্যাড ইন্টিগ্রেশন)
├── admin.html        (সুপার অ্যাডমিন মোবাইল স্টুডিও — লাইভ এডিট, ডিলিট, সিঙ্গেল রুট লক ও গিটহাব সিঙ্ক)
├── logo.png          (আপনার ব্র্যান্ড লোগো)
└── data/
    └── apps.json     (অ্যাপ্লিকেশনের ডেটাবেজ স্কিমা)
```

## 🚀 হোস্ট করার নিয়ম:
1. আপনার GitHub-এ যান এবং `snappshub.github.io` রিপোজিটরিতে এই ফাইলগুলো আপলোড করুন।
2. Settings > Pages এ যান এবং Branch: `main` / Folder: `/ (root)` সিলেক্ট করে Save করুন।
3. আপনার ওয়েবসাইট সম্পূর্ণ লাইভ!
